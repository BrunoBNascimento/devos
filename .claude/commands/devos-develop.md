Read and execute the DevOS development workflow at `.devos/workflows/dev_workflow.md`.

This executes the complete development lifecycle:
- Phase 0: Task selection (wizard-based)
- Phase 1: Discovery (local repos)
- Phase 2: Knowledge consultation (silent)
- Phase 3: Planning with DAG generation
- Phase 4: Execution following DAG order
- Phase 5: Verification (build, lint, test)
- Phase 6: Review (KB cross-reference)
- Phase 7: Delivery (PR + Brain sync)

All code changes are LOCAL-FIRST — files are read/written in `repositories_path`.
